# RAG 检索增强生成概述

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将外部知识检索与大语言模型生成相结合的技术方案。

## 核心流程

1. **文档准备**：将原始文档加载、解析并切分为较小的文本块（chunk）。
2. **向量化**：使用 Embedding 模型将每个文本块转换为向量。
3. **入库**：把向量与原文写入向量数据库（例如 Milvus）。
4. **检索**：用户提问时，将问题同样向量化，在向量库中找出最相似的若干文本块。
5. **生成**：把检索到的文本块作为上下文交给大语言模型，生成有依据的回答。

## 主要优点

- **减少幻觉**：回答基于检索到的真实文档，而不是模型凭空记忆。
- **知识可更新**：更新知识库只需重新写入文档，不需要重新训练模型。
- **可追溯**：回答可以附带引用的原文片段，便于人工核对。

## 常用组件

- 分块器：SentenceSplitter，按句子边界切分，支持设置块大小与重叠。
- 向量库：Milvus、Zilliz Cloud 等。
- 编排框架：LlamaIndex 负责数据与检索，LangGraph 负责智能体状态与工具调用循环。
